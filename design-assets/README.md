# Saydaliyati Design Assets

This folder is reserved for approved visual assets used by the implementation.

Recommended structure:

```text
design-assets/
├── brand/
├── icons/
├── illustrations/
├── ui-references/
└── generated-concepts/
```

The textual design source of truth remains `DESIGN-SYSTEM.md`.

Do not treat screenshots or generated concepts as implementation truth when they conflict with the design system.
